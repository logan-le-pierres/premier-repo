# Site de coutellerie artisanale — Cévennes

Boutique en ligne pour un coutelier artisan : quelques dizaines de couteaux uniques, une clientèle plutôt âgée, un site très épuré.

## Contenu

- [`docs/01-choix-technique.md`](docs/01-choix-technique.md) : CMS ou sur mesure ? Architecture recommandée (Next.js + Payload CMS + Stripe Checkout).
- [`docs/02-obligations-legales.md`](docs/02-obligations-legales.md) : CGV, rétractation, RGPD, paiements, comptabilité, spécificités des couteaux (France, 2026).
- [`maquettes/`](maquettes/index.html) : deux propositions graphiques en HTML statique. Ouvrir `maquettes/index.html` dans un navigateur.
  - **A « Atelier »** (recommandée) : accueil, catalogue, fiche couteau, panier.
  - **B « Schiste »** : variante sombre, page d'accueil.

Le nom « Coutellerie du Mas », les coordonnées, les prix et les textes des maquettes sont provisoires. Les images sont des recadrages des photos prises au marché.
